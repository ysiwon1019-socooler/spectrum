# 스펙트럼 입장진술문

개념기반 탐구수업의 사고전략 **스펙트럼 입장진술문**을 교실 화면에서 진행하기 위한 웹페이지입니다.

## 사용 방법

1. `index.html`을 브라우저(크롬·엣지 권장)로 엽니다.
2. 처음 나오는 창에 학생 이름을 한 줄에 한 명씩(또는 쉼표로 구분해) 입력하고 **이름표 만들기**를 누릅니다.
3. 보라색 글상자를 눌러 입장진술문을 입력합니다.
4. 학생들은 맨 아래 **이름표 보관함**에서 자기 이름표를 끌어 스펙트럼 위 원하는 자리에 놓습니다.
   - 파란 이름표 → 수업 전 칸, 빨간 이름표 → 수업 후 칸
   - 보관함에 다시 놓으면 이름표가 돌아갑니다.
   - 키보드: 이름표를 선택하고 `1`~`5`(매우 반대~매우 동의), `0`(보관함)
5. **입장 변화 보기**로 학생별 수업 전·후 입장 변화를 표로 확인하며 성찰 질문을 나눕니다.

입장진술문, 명단, 이름표 위치는 이 브라우저에 자동 저장되어 다시 열어도 이어서 쓸 수 있습니다.
